# mutmut Integration Guide

dataframe-mutator is a **mutmut extension** that adds Polars DataFrame support to Python's premier mutation testing framework.

## What is dataframe-mutator?

dataframe-mutator **enhances mutmut** with:

- ✅ **109 Polars operators** - Mutation operators specific to Polars operations
- ✅ **Smart filtering** - Skip low-value mutations (column names, string literals)
- ✅ **Semantic analysis** - Understand Polars code structure and prioritize mutations
- ✅ **Zero learning curve** - Works exactly like mutmut

## Installation

```bash
# Install with Polars support
pip install dataframe-mutator[polars]

# Or standalone (mutmut will auto-discover the plugin)
pip install dataframe-mutator
```

## Usage

### Option 1: Automatic Plugin Discovery

Once installed, mutmut automatically discovers and uses dataframe-mutator:

```bash
# Just use mutmut as normal - Polars optimization is automatic!
mutmut run

# With options
mutmut run --tests-dir tests/ --paths src/
```

### Option 2: Explicit Plugin Loading

```bash
# Explicitly load the Polars extension
mutmut run --plugin polars
```

### Option 3: Configuration

Configure behavior in `pyproject.toml`:

```toml
[tool.dataframe-mutator]
# Enable Polars optimization
enabled = true

# Skip low-value mutations
skip_low_value_mutations = true

# Semantic analysis
enable_semantic_analysis = true

# Which filters to apply
filters = [
    "column_names",      # Skip column name mutations
    "string_literals",   # Skip non-query strings  
    "syntax_only",       # Skip syntax-only changes
]

# Operators to register
operators = "all"  # or list specific: ["filters", "selects", "aggregations"]
```

## How It Works

### 1. Mutation Generation

mutmut generates mutations of your Python code using AST manipulation. dataframe-mutator enhances this with Polars-specific operators:

```python
# Original code
df.filter(pl.col("age") > 18).select("name", "age")

# Possible mutations generated by dataframe-mutator:
# - Change filter condition: > to <, >= to <=, == to !=
# - Change selection: include/exclude columns
# - Change aggregations: sum to mean, count to max
# ... (109 operator types)
```

### 2. Smart Filtering

Not all mutations are meaningful. dataframe-mutator filters before testing:

```python
# Mutation: column name "age" → "ages"
# Skip? YES - column "ages" doesn't exist, always fails ✓

# Mutation: filter > to <  
# Skip? NO - might pass tests incorrectly ✗

# Mutation: string literal "foo" → "bar"
# Skip? YES - usually not domain-relevant ✓
```

### 3. Semantic Analysis

dataframe-mutator analyzes your code to understand:

- What columns are referenced
- What operations are used
- What aggregations are performed
- What filters are applied

This helps prioritize testing meaningful mutations.

## Examples

### Example 1: Simple Polars ETL

```python
# src/etl.py
import polars as pl

def process_data(df: pl.DataFrame) -> pl.DataFrame:
    return (
        df
        .filter(pl.col("amount") > 100)
        .with_columns([
            (pl.col("amount") * 1.1).alias("adjusted"),
        ])
        .select(["id", "amount", "adjusted"])
    )
```

```bash
# Run mutation testing
$ mutmut run

# dataframe-mutator adds operators for:
# - Filter conditions: >, <, >=, <=, ==, !=
# - Column operations: select, with_columns, drop
# - Transformations: *, +, -, /

# Smart filtering eliminates:
# - "amount" → "amounts" mutations (column doesn't exist)
# - String literal mutations (not relevant)
# - Syntax-only changes
```

### Example 2: Complex Aggregations

```python
# src/analytics.py
def daily_summary(transactions: pl.DataFrame) -> pl.DataFrame:
    return (
        transactions
        .group_by("date")
        .agg([
            pl.col("amount").sum().alias("total"),
            pl.col("amount").mean().alias("avg"),
            pl.col("id").count().alias("count"),
        ])
        .sort("date")
    )
```

```bash
# mutmut with dataframe-mutator detects mutations like:
# - sum() → mean(), count(), max() (aggregation swaps)
# - sort ascending → descending
# - group_by field changes

# Smart filtering skips:
# - Column name changes (would break queries)
# - Redundant filters
```

## Configuration Reference

### Filter Options

```toml
[tool.dataframe-mutator.filters]
# Skip mutations of column names
skip_column_names = true

# Skip mutations of string literals
skip_string_literals = true

# Skip syntax-only changes
skip_syntax_only = true

# Skip low-value mutations overall
skip_low_value_mutations = true
```

### Operator Selection

```toml
[tool.dataframe-mutator.operators]
# Enable all 109 operators
all = true

# Or select specific categories:
filters = true
selects = true
aggregations = true
joins = true
window_functions = true
datetime_operations = true
# ... (109 total)
```

### Semantic Analysis

```toml
[tool.dataframe-mutator.analysis]
# Enable semantic analysis
enabled = true

# Cache analysis results
cache = ".mutmut-polars-cache"

# Prioritize mutations by type
prioritize = [
    "filter_boundaries",     # Most important
    "aggregation_swaps",
    "operation_changes",
    "column_mutations",      # Least important
]
```

## Troubleshooting

### Plugin Not Loading

```bash
# Verify the plugin is installed
pip show dataframe-mutator

# Check if mutmut can discover it
python -c "from dataframe_mutator.mutmut_plugin import get_plugin; print(get_plugin())"
```

### No Mutations Found

```bash
# This is normal - smart filtering might eliminate all low-value mutations
# Add --no-filter to test all mutations:
mutmut run --no-polars-filter

# Or check if your code has Polars operations:
grep -r "pl\." src/
```

### Slow Performance

```bash
# Disable semantic analysis if it's slow
[tool.dataframe-mutator]
enable_semantic_analysis = false

# Or reduce operators:
[tool.dataframe-mutator.operators]
all = false
filters = true
selects = true
aggregations = true
```

## API Reference

### Programmatic Usage

```python
from dataframe_mutator.mutmut_plugin import get_plugin
from dataframe_mutator.filters import PolarsMutationFilter

# Get plugin instance
plugin = get_plugin()

# Create filter
filter = PolarsMutationFilter({
    "skip_column_names": True,
    "skip_string_literals": True,
})

# Check if mutation should be tested
should_test = filter.should_mutate(original_code, mutated_code)
```

### Semantic Analysis

```python
from dataframe_mutator.filters import SemanticMutationAnalyzer

# Analyze code
analyzer = SemanticMutationAnalyzer(code)

# Get analysis
summary = analyzer.summarize()
print(summary)
# {
#   "columns": ["id", "amount", "date"],
#   "operations": ["filter", "select", "group_by"],
#   "aggregations": ["sum", "mean", "count"],
#   ...
# }

# Check if mutation is meaningful
is_meaningful = analyzer.is_meaningful_mutation(original, mutated)
```
